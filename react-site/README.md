# The Javawockee — React Scaffold

This folder contains a minimal Vite + React scaffold with Framer Motion for animations.

Quick start

1. Open a terminal in `react-site`
2. Install dependencies:

```bash
npm install
```

3. Run the dev server:

```bash
npm run dev
```

Notes
- This is a starting point. You can migrate content from the root HTML pages into React routes/components.
- To use the React plugin for Vite, dependencies include `@vitejs/plugin-react` (already listed in `package.json`).
